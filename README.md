## Behind the Scenes
During testing and validation, I ran into HTML structure and form issues—including an unclosed `<main>` landmark, duplicate `id` attributes on form controls, stray `<option>` tags outside a `<select>` wrapper, and a `404` console message for `favicon.ico`. I fixed each issue by closing `<main>` before `<footer>`, assigning unique `id`s and matching `<label>` elements, wrapping the topic choices inside a proper `<select>` element, and adding an icon link in `<head>` before re-validating and pushing the final changes.
